# Varnika Studios

Static bilingual website. Open index.html or serve this folder with `python3 -m http.server 8000`.

Pages: home, small business, public leaders, influencers, services/packages, contact.
Styles: assets/css/style.css. Behaviour: assets/js/main.js. Logo: assets/images/varnika-logo.png.
English/Hindi choices persist in localStorage. Google Fonts are optional; system fonts work offline.

Original website preserved in backup/index-original.html and backup/original-site.zip.
PDF slots are deliberately marked coming soon until approved documents are supplied. Instructions: assets/downloads/README.md.
The contact form downloads a local text brief; it does not submit information. The Facebook link comes from the original site. Add a verified phone/email when available.
Forecast copy describes ±10–15% as a planning target, not a performance guarantee. No unverified testimonials or past results are included.
